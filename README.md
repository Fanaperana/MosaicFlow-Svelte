## 🧪 What is this?

MosaicFlow is a powerful desktop app for building visual knowledge graphs — connect ideas, research, and notes as nodes on an infinite canvas. Built with Tauri 2.0 + Svelte 5 for a native, lightweight experience.

## ✨ Features

- 🧩 Drag-and-drop node-based canvas (powered by xyflow)
- 🔗 Connect nodes with typed relationships
- 📝 Rich text content per node
- 🖥️ Native desktop app (Tauri 2.0 — Rust backend)
- ⚡ Svelte 5 + TypeScript frontend
- 🎨 Tailwind CSS styling

## 🚀 Getting Started

```bash
npm install
npm run tauri dev
npm run tauri build
```
