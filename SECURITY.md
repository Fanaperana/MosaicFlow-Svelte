# Security Policy

## Supported Versions

Security fixes are applied to the latest code on the main branch.

| Version | Supported |
| --- | --- |
| main | yes |
| older releases | no |

## Reporting a Vulnerability

Please do not report vulnerabilities via public GitHub issues.

Use one of these channels:

- GitHub Security Advisories (preferred):
  https://github.com/Fanaperana/MosaicFlow-Svelte/security/advisories/new
- If advisories are unavailable, open a private report by contacting repository maintainers through GitHub.

Please include:

- A clear description of the issue
- Steps to reproduce
- Potential impact
- Suggested fix (if available)

## Response Targets

- Initial acknowledgment: within 7 days
- Status update: within 14 days when triage is complete

## Disclosure Policy

We follow coordinated disclosure and will credit reporters who want attribution.
